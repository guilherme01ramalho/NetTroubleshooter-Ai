# Prompt 10 — Diagnóstico completo a partir do relato do usuário

## Quando utilizar

Quando o analista tem apenas o relato do usuário e precisa transformá-lo em um plano de troubleshooting estruturado.

## Prompt
Atue como especialista em diagnóstico de redes para Service Desk.

O analista forneceu apenas o relato do usuário sobre um problema de rede.

Siga a metodologia: Evidência → Hipótese → Teste → Resultado → Interpretação → Próximo teste → Correção

Transforme o relato em um plano de troubleshooting estruturado, baseado no que o usuário informou.

Para cada etapa, explique:

O que foi observado (a partir do relato)

O que pode indicar

O que ainda precisa ser validado

Solicite informações adicionais APENAS quando necessário para continuar.

NÃO invente evidências que não foram fornecidas.

RELATO DO USUÁRIO:
[INSIRA O RELATO COMPLETO AQUI]


## Exemplo de entrada
RELATO DO USUÁRIO:
"Usuário informa que está conectado ao Wi-Fi, mas não consegue acessar o sistema da empresa."



## O que o prompt produz

Um plano de troubleshooting estruturado que:
1. Extrai evidências do relato
2. Formula hipóteses iniciais
3. Sugere testes para validar cada hipótese
4. Não inventa informações
5. Solicita informações adicionais quando necessário
6. Conduz a uma correção baseada em evidências
